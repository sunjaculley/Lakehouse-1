# Architecture rules
- Use TanStack Router leaf routes for named content areas; retain existing internal guide URLs so references continue working.
- Keep client experience content in a browser-safe module separate from internal guide content; the persona switch is presentation only, never authorization.
- Preserve the existing local rich-text and photo overlay system and stable edit IDs; do not imply edits are shared automatically.
- Compose the attached AD Blue Thunder components from its local barrel and use its tokens; KPMG Bold is the explicitly requested headline font exception.
- Standalone concept exports are separate versioned deliverables; no export transformation should change the app's source imagery.
- Keep campus map geometry in a browser-safe data module and interactive SVG controls in LakehouseMap; reuse visitor destination content so map and list cannot diverge. Supplied SVG artwork and its coordinate-space pin sizes are intentional visual exceptions to layout tokens.
